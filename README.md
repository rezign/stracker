# 📈 個人資產管理系統 (Personal Asset Management System)

這是一個基於 Python Streamlit 構建的投資組合追蹤工具。專為台股投資人設計，支援**現股、融資、融券及當沖**等多種交易模式。

本系統不僅能記錄交易，還能自動計算**手續費、證交稅、融資利息**，並採用 **FIFO (先進先出)** 邏輯精準計算已實現損益與勝率。

---

## 🚀 快速開始 (Quick Start)

### 1. 安裝必要套件
在終端機 (Terminal) 執行以下指令安裝依賴庫：
```bash
pip install streamlit yfinance pandas plotly
'''
## 2. 啟動系統
```bash
streamlit run app.py
'''
📖 使用指南 (User Guide)
--------------------
 
## 1\. 📝 交易登錄 (左側側邊欄)
 
這是系統的核心入口，所有的買賣紀錄都在此輸入。
 
*   **股票代碼**：
    
 
*   支援輸入台股代號 (如 `2330`)，系統會自動嘗試抓取名稱。
    
*   若系統找不到，可嘗試完整代碼 (如 `2330.TW` 或 `8069.TWO`)。
    
 
*   **交易模式 (Mode)**：
    
 
*   專用的當沖計算機。
    
*   輸入「買價」與「賣價」，系統自動以 **0.15% (當沖稅率)** 計算淨獲利。
    
*   **賣出**：做空，需繳納保證金 (預設 90%)。
    
*   **買進 (回補)**：回補時退還保證金與擔保品。
    
*   **買進**：可設定融資成數 (預設 60%)，系統會自動計算「自備款」與「借款金額」。
    
*   **賣出**：系統依據持有天數自動計算**融資利息**並扣除成本。
    
*   **Spot (現股)**：一般買賣，自動計算 0.1425% 手續費與 0.3% 證交稅。
    
*   **Margin (融資)**：
    
*   **Short (融券)**：
    
*   **Day Trade (現股當沖)**：
    
 
*   **智能驗證**：
    
 
*   當你選擇「賣出」時，可以點擊 **🔍 試算損益**，系統會預覽這筆交易會賺多少錢，以及償還多少融資金額。
    
 
## 2\. 📊 資產儀表板 (Tab 1)
 
登入後的主畫面，讓你一眼掌握目前持倉狀況。
 
*   **即時市值**：透過 Yahoo Finance 自動更新最新股價。
    
*   **紅綠配色**：符合台股習慣，**紅色代表獲利**，**綠色代表虧損**。
    
*   **視覺化圖表**：
    
 
*   **甜甜圈圖**：檢視資產配置佔比。
    
*   **長條圖**：快速找出哪支股票是獲利主力，哪支是拖油瓶。
    
 
*   **持倉明細表**：
    
 
*   每一列會根據該股的損益自動變色。
    
*   「現價」欄位會動態更新。
    
 
## 3\. 💰 歷史績效與分析 (Tab 2)
 
這裡展示你「已經賣出 (平倉)」的戰績。
 
*   **篩選功能**：可自選年份或日期區間 (例如：只想看 2024 年績效)。
    
*   **關鍵指標 (KPI)**：
    
 
*   **盈虧比 (Profit Factor)**：總獲利 / 總虧損。大於 1.5 通常代表策略健康。
    
*   **平均賺賠比**：平均贏一次賺多少 vs 輸一次賠多少。
    
 
*   **資金累計曲線 (Equity Curve)**：
    
 
*   透過圖表觀察你的資產是否穩定向上增長。
    
*   若曲線波動劇烈，代表風險控制可能需要調整。
    
 
## 4\. 🛠️ 資料維護與修正 (Tab 3 & 進階功能)
 
*   **刪除交易**：
    
 
*   在「交易明細」頁籤中，輸入 ID 即可刪除錯誤的紀錄。
    
 
*   **批量修改名稱**：
    
 
*   若想將「台積電」統一改名為「2330-台積電」，可使用批量修改功能一次更新所有歷史紀錄。
    
 
*   **🔄 重算所有歷史損益 (Replay)**：
    
 
*   **這是最重要的修復功能**。
    
*   如果你在今天補登了「上個月」的交易，會導致 FIFO (先進先出) 順序錯亂。
    
*   點擊此按鈕，系統會像時光機一樣，依照日期重新跑一次所有交易，校正所有的成本與利息計算。

⚠️ 注意事項
-------
 
1.  **股價更新**：系統會在第一次載入或點擊重新整理時，透過網路抓取股價，請確保網路連線正常。
    
2.  **除權息**：目前的價格資料庫未完全自動處理歷史除權息的股價回溯，建議定期使用「強制重抓所有股價」功能保持數據新鮮。
