# 📈 個人資產管理系統 (Personal Asset Management System)

這是一個基於 Python Streamlit 構建的投資組合追蹤工具。專為台股投資人設計，支援**現股、融資、融券、當沖、權證及期貨**等多種交易模式。

本系統不僅能記錄交易，還能自動計算**手續費、證交稅、融資利息**，並採用 **FIFO (先進先出)** 邏輯精準計算已實現損益與勝率。

---

## 🚀 快速開始 (Quick Start)

### 1. 安裝必要套件
```bash
pip install streamlit yfinance pandas plotly requests
```

### 2. 啟動系統
```bash
streamlit run app.py
```

## 📖 使用指南 (User Guide)

### 1. 📝 交易登錄 (左側側邊欄)

側邊欄分為三個獨立登錄區塊：

---

#### 🏷️ 股票交易登錄

適用於現股、融資、融券、當沖。

- **股票代碼**：輸入台股代號 (如 `2330`) 後按 Enter，系統自動驗證並鎖定。若找不到可嘗試完整代碼 (如 `2330.TW` 或 `8069.TWO`)。

- **交易模式 (Mode)**：

  | 模式 | 說明 |
  |------|------|
  | **Spot (現股)** | 一般買賣，0.3% 證交稅（ETF 代號 `00` 開頭為 0.1%）|
  | **Margin (融資)** | 買進可設定融資成數（預設 60%），賣出自動計算融資利息 |
  | **Short (融券)** | 賣出需繳保證金（預設 90%），買進（回補）退還保證金 |
  | **Day Trade (現股當沖)** | 輸入買價與賣價，以 0.15% 當沖稅率計算淨獲利 |

- **🔍 試算損益**：選擇賣出時可預覽損益，包含 FIFO 成本、融資還款金額。

---

#### 🎫 權證登錄

適用於台灣上市權證（買進型 Call / 賣出型 Put）。

> 權證代號（如 `051638`）無法透過 Yahoo Finance API 驗證，須手動輸入，系統會自動補上 `.TW` 後綴。

- **即時試算**：填入股數與價格後，側邊欄即時顯示：
  - 手續費（0.1425% 打六折）
  - 稅金（固定 **0.1%**）
  - **Buy → 應付款**、**Sell → 應收款 (預估)**

- **🔍 試算損益**：賣出時可預覽 FIFO 成本與預估獲利。

---

#### 📊 期貨登錄

適用於台指期 (TX)、小台 (MTX)、個股期貨等。期貨資料存於獨立的 `futures_trades` 資料表。

支援三種操作：

| 操作 | 說明 |
|------|------|
| **開倉** | 填入代號、方向（多/空）、口數、點位、乘數、保證金 |
| **逐日結算** | 選擇已開倉部位，輸入當日結算損益（正為盈餘，負為扣款）|
| **平倉** | 選擇部位，填入平倉點位，系統以 FIFO 自動計算實現損益 |

常見乘數：台指期 200 元/點、小台 50 元/點、個股期貨 2000 元/點。

---

### 2. 📊 資產儀表板 (Tab 1)

- **即時市值**：透過 Yahoo Finance 自動更新股價。對 yfinance 無法支援的標的（如權證），自動改抓 `tw.stock.yahoo.com` 網頁資料。
- **紅綠配色**：符合台股習慣，**紅色代表獲利，綠色代表虧損**。
- **視覺化圖表**：
  - 甜甜圈圖：資產配置佔比
  - 長條圖：個股未實現損益
- **股票持倉明細**：顯示平均成本、現價、損益金額、報酬率
- **期貨持倉區塊**（有開倉部位才顯示）：顯示方向、口數、建倉點、未實現損益、累積結算損益、保證金

---

### 3. 💰 歷史績效與分析 (Tab 2)

顯示所有已平倉（已賣出）的交易紀錄與統計。

- **日期區間篩選**
- **關鍵指標 (KPI)**：
  - 區間總損益
  - 交易勝率（勝/敗筆數）
  - 盈虧比 (Profit Factor)
  - 平均賺賠比
- **資金累計損益曲線**
- **個股損益貢獻排行**
- **股票交易明細表**
- **期貨已實現損益區塊**（有平倉紀錄才顯示）

---

### 4. 🛠️ 資料維護 (Tab 3 & 進階功能)

- **交易明細**：查看完整流水帳，可依 ID 刪除錯誤紀錄
- **批量修改名稱**：將同一代碼的所有歷史紀錄統一改名
- **🔄 重算所有歷史損益 (Replay)**：補登舊日期交易後必須執行，系統會按時間重新計算所有 FIFO 成本與損益
- **🔄 強制重抓所有股價**：清除本地股價快取，重新從 Yahoo Finance 抓取（可修正除權息問題）

## ⚙️ 費率設定

| 項目 | 費率 | 說明 |
|------|------|------|
| 手續費 | 0.1425% × 0.6 | 買賣雙方皆收，低消 20 元 |
| 證交稅（現股） | 0.3% | 賣出時收取 |
| 證交稅（ETF） | 0.1% | 代號 `00` 開頭自動判斷 |
| 證交稅（當沖） | 0.15% | 當沖模式專用 |
| 證交稅（權證） | 0.1% | Call / Put Warrant 固定 |
| 融資利率 | 6.25% / 年 | 按實際持有天數計息 |

## 🗄️ 資料庫結構

檔案名稱：`investment_data_final.db`（SQLite）

| 資料表 | 用途 |
|--------|------|
| `transactions` | 股票、融資、融券、當沖、權證所有交易紀錄 |
| `price_history` | 本地股價快取（每日收盤價） |
| `futures_trades` | 期貨開倉 / 逐日結算 / 平倉紀錄 |

## ⚠️ 注意事項

1. **股價更新**：系統載入時自動抓取最新股價，請確保網路連線正常。
2. **權證股價**：yfinance 不支援台灣權證，系統改從 `tw.stock.yahoo.com` 擷取現價。
3. **期貨現價**：yfinance 不支援台灣期貨，期貨持倉的未實現損益需手動確認；欄位顯示「—」為正常。
4. **除權息**：建議定期使用「強制重抓所有股價」保持股價資料正確。
5. **補登舊交易**：補登任何過去日期的交易後，請執行「重算所有歷史損益」以校正 FIFO 順序。
