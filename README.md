📈 個人資產管理系統 (Personal Asset Management System)
==============================================

這是一個基於 **Python Streamlit** 構建的台股投資組合追蹤工具。專為台灣市場設計，完整支援**現股、融資、融券及當沖**等多種交易模式。

本系統不僅能記錄交易，核心特色在於能自動處理台股複雜的交易成本（手續費、證交稅、融資利息），並採用 **FIFO (先進先出)** 邏輯，精準計算已實現損益與勝率。

🚀 快速開始 (Quick Start)
---------------------

### 1\. 安裝必要套件

請確保你的環境已安裝 Python，並在終端機 (Terminal) 執行以下指令安裝依賴庫：

`   pip install streamlit yfinance pandas plotly   `

### 2\. 啟動系統

在專案目錄下執行：

`   streamlit run app.py   `

# 📈 個人資產管理系統 (Personal Asset Management System) v1.5

這是一個基於 **Python Streamlit** 構建的台股投資組合追蹤工具。專為台灣市場設計，完整支援**現股、融資、融券及當沖**等多種交易模式。

本系統不僅能記錄交易，核心特色在於能自動處理台股複雜的交易成本（手續費、證交稅、融資利息），並採用 **FIFO (先進先出)** 邏輯，精準計算已實現損益與勝率。

---

## 🚀 功能特色 (Features)

- **完整交易支援**：現股 (Spot)、融資 (Margin)、融券 (Short)、當沖 (Day Trade)。
- **自動成本計算**：內建台股交易稅率、手續費折讓、融資利息 (按日計息)、融券保證金計算。
- **FIFO 演算法**：精確處理分批買進、分批賣出的成本認定，解決一般 Excel 難以計算的痛點。
- **視覺化儀表板**：整合 Plotly 互動式圖表，提供資產配置圓餅圖、損益長條圖及**資產淨值曲線**。
- **資料安全**：採用 SQLite 本地資料庫，並支援一鍵備份/還原。

---

## 📖 使用指南 (User Guide)

### 1. 📝 交易登錄 (左側側邊欄)

這是系統的核心入口，所有的買賣紀錄都在此輸入。

#### **A. 股票代碼 (Ticker)**
* **智能搜尋**：支援輸入台股代號 (如 `2330`)，系統會自動嘗試抓取名稱。
* **完整代碼**：若系統找不到，可嘗試輸入完整 Yahoo Finance 代碼 (如 `2330.TW` 或 `8069.TWO`)。

#### **B. 交易模式 (Mode)**
系統針對不同交易類別提供專屬計算邏輯：

* **Spot (現股)**
    * 一般買賣，自動計算 **0.1425%** 手續費與 **0.3%** 證交稅。
* **Margin (融資)**
    * **買進**：可設定融資成數 (預設 60%)，系統自動計算「自備款」與「借款金額」。
    * **賣出**：系統依據持有天數，按日自動計算**融資利息**並扣除成本。
* **Short (融券)**
    * **賣出 (做空)**：需繳納保證金 (預設 90%)。
    * **買進 (回補)**：回補時退還保證金與擔保品。
* **Day Trade (現股當沖)**
    * 專用的當沖計算機。
    * 輸入「買價」與「賣價」，系統自動以 **0.15% (當沖稅率)** 計算淨獲利。

> **💡 智能驗證功能**：
> 1. 當你選擇「賣出」時，可以點擊 **🔍 試算損益**，預覽預計賺賠與償還金額。
> 2. 系統具備**防呆機制**，輸入價格或股數 <= 0 時會拒絕寫入，並透過 Toast 訊息提示。

#### **C. 資料備份 (Backup)**
* 位於側邊欄最下方，提供 **📦 資料庫備份與還原** 功能，可隨時下載 `.db` 檔或上傳覆蓋，確保資料安全。

### 2. 📊 資產儀表板 (Dashboard)

登入後的主畫面，讓你一眼掌握目前持倉 (Open Positions) 狀況。

* **即時市值**：透過 Yahoo Finance API 自動更新最新股價。
* **紅綠配色**：符合台股習慣，🔴 **紅色代表獲利**，🟢 **綠色代表虧損**。
* **視覺化分析**：
    * **資產配置圖**：甜甜圈圖檢視持股權重。
    * **個股損益圖**：快速找出獲利主力與虧損拖油瓶。
    * **帳戶淨值曲線 (Equity Curve)**：(v1.5 新增) 追蹤帳戶總資產隨時間變化的趨勢圖。
* **持倉明細表**：每一列根據損益自動變色，「現價」欄位會動態更新。

### 3. 💰 歷史績效 (History & Analysis)

這裡展示你「已經賣出 (已平倉)」的戰績。

* **篩選功能**：可自選年份或日期區間 (例如：只想看 2024 年績效)。
* **關鍵指標 (KPI)**：
    * **盈虧比 (Profit Factor)**：總獲利 / 總虧損。大於 1.5 通常代表策略健康。
    * **平均賺賠比**：平均贏一次賺多少 vs. 輸一次賠多少。
* **累計損益曲線**：透過圖表觀察已實現獲利的增長趨勢。

### 4. 🛠️ 資料維護 (Transactions & Settings)

* **刪除交易**：在「交易流水帳」頁籤中，輸入 ID 即可刪除錯誤的紀錄。
* **批量修改名稱**：可將「台積電」統一改名為「2330-台積電」，一次更新所有歷史紀錄。
* **🔄 重算所有歷史損益 (Replay)**：
    * **這是最重要的修復功能！**如果你在今天補登了「上個月」的交易，會導致 FIFO (先進先出) 順序錯亂。
    * 點擊此按鈕，系統會像時光機一樣，依照日期重新跑一次所有交易，校正所有的成本與利息計算，並修復浮點數誤差。

## ⚙️ 系統參數 (Parameters)

可於程式碼最上方 `config` 區域修改全域常數：

| 項目 | 費率/設定 | 說明 |
| :--- | :--- | :--- |
| **手續費** | 0.1425% | 券商公定價，預設打 **6 折** 計算 |
| **手續費低消** | 20 元 | 低於 20 元以 20 元計 |
| **證交稅 (一般)** | 0.3% | 現股賣出時收取 |
| **證交稅 (ETF)** | 0.1% | 代號 00 開頭自動判斷適用此稅率 |
| **證交稅 (當沖)** | 0.15% | 選擇當沖模式時專用 |
| **融資利率** | 6.25% | 年利率，按日計息 |
| **資料庫** | SQLite | 檔案名稱：`investment_data_final.db` |

## ⚠️ 注意事項

1.  **股價更新**：系統會在第一次載入或點擊重新整理時，透過網路抓取股價，請確保網路連線正常。
2.  **除權息**：目前的價格資料庫主要依賴 Yahoo Finance (已開啟自動調整)，若遇資料缺失，可使用維護區的「強制重抓所有股價」功能。
